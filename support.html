A good place to start

From copy
to keeper.

A few useful habits for your Mac.

  1. 01

    Copy as usual.

    Enable automatic capture in Settings → Capture, then use ⌘C in your apps. You can pause capture, exclude apps or save manually instead.

  2. 02

    Find it on your shelf.

    Open Shelf-ish from the menu bar. Search for a clip, open its preview or copy it to use again. Quick Paste gives you another way to search and paste.

  3. 03

    Pin the keepers.

    Pin what you want to keep. Unpinned clips can expire on your schedule, leaving a little more room for the next useful thing.

SafariPage title, link and optional nearby textOut now
  1. In Shelf-ish’s Connectors settings, switch on Safari and choose Open Safari Extensions.
  2. Enable Shelf-ish in Safari, accept its capture disclosure and choose the website access you want to allow.
  3. Copy selected webpage text as usual with ⌘C. With capture enabled, the saved clip can keep its page title, source link and optional surrounding text.

Safari manages website permissions. You can pause capture or change your surrounding-text choice in the extension.

ChromePage title, link and optional nearby textOut now
  1. Install Shelf-ish 1.2 or later on macOS 26 or later. In Settings → Capture, enable clipboard monitoring; in Settings → Connectors, switch on Chrome/source context.
  2. Install the free Shelf-ish Chrome extension. Accept its capture disclosure and website access.
  3. Open the extension’s Connection & privacy settings, choose Connect to Shelf-ish and approve the connection in the Mac app once.
  4. Select webpage text and copy as usual with ⌘C. Open the saved clip to see its page title, source link and optional surrounding text.

You can turn surrounding text off, pause a site or disconnect in the extension. Private windows, password fields and browser-internal pages are excluded. Some custom editors and copy buttons do not provide source context.

ExcelWorkbook, sheet, range and available labelsOut now
  1. Keep automatic clipboard capture enabled in Shelf-ish → Settings → Capture.
  2. In Settings → Connectors, switch on Excel. No add-in or separate connection is needed.
  3. Copy a continuous range of cells with ⌘C. Open the saved clip to see the workbook, sheet and range details supplied by Excel.

Headers and row context depend on the data Excel provides. Source links are included only when available; missing metadata is not guessed.

ObsidianNote link, line range and nearby passageOut now
  1. Enable the Shelf-ish plug-in in Obsidian and switch on Obsidian in Shelf-ish → Settings → Connectors.
  2. Choose Shelf-ish · Connect in Obsidian’s status bar, then approve the connection in Shelf-ish once.
  3. Select text in a saved Markdown note and copy with ⌘C. If you have just approved the connection, copy the selection again.

Keep Shelf-ish’s automatic capture enabled. The clip can retain its note link, line range and a bounded nearby passage.

VS CodeFile, line range and surrounding codeOut now
  1. Enable the Shelf-ish extension in VS Code and switch on Visual Studio Code in Shelf-ish → Settings → Connectors.
  2. Click Shelf-ish: Connect in VS Code’s status bar and approve the connection in Shelf-ish once.
  3. Select code in a local file editor and copy with ⌘C. If you have just approved the connection, copy the selection again.

Keep automatic capture enabled. Context capture applies to selected text in local file editors; other views keep their existing copy behaviour.

Quick answers

A little
less head-scratching.

Capture, context, sync and the other useful details.

Which devices can I use now?

The Mac app is available now, including its supporting widgets. iPhone is coming soon. The Duo, Watch and Vision Pro artwork previews wider-platform work; it does not mean every version is available to download yet.

Does the app watch my clipboard all the time?

On Mac, automatic clipboard capture is optional. You can pause capture, exclude apps or save manually instead. The forthcoming iPhone app uses explicit clipboard saves and the share sheet; it does not continuously monitor the clipboard.

Does Shelf-ish sync across devices?

Clips are stored locally on each device. With iCloud sync enabled and available, saved clips and their context can sync through your own iCloud account. You can use Shelf-ish on one Mac without enabling sync.

If sync is not working, tell us which devices are involved, whether they use the same iCloud account, and what you see on each. Please do not send account details or private clip content.

How do expiring clips work?

Unpinned clips can expire automatically after a set time. Pin important clips to keep them, or snooze their expiry when you need a little longer.

Which connectors are available?

Safari, Chrome, Excel, Obsidian and VS Code context are out now for Mac. Chrome requires Shelf-ish 1.2 or later and the separate Chrome Web Store extension. Slack is coming soon. Find your connector’s setup steps, then check your installed app’s Settings for the features available in that version.

Does context capture read everything?

No. It works with eligible copies from sources you enable, subject to their permissions. Where supported, surrounding text is optional. Pause capture or switch off a source when you want it left alone. Missing source details are not guessed.

Do summaries require Apple Intelligence?

The optional language tools require a supported Mac with Apple Intelligence enabled, its on-device models ready, and a supported language and region. Capture, search and paste work without them. Review generated summaries and suggested code changes before using them.

Why is a preview or transcript missing?

Link previews may need a network connection. Transcription and intelligence features also depend on permissions, supported capabilities and any required model downloads. Check the relevant settings, then try again. If it persists, tell us which type of clip is affected.

What if the app feels slow or stuck?

Quit and reopen Shelf-ish, then check whether the issue affects one clip or every clip. If it persists, send the steps to reproduce it along with your app and operating system versions.

What to include
