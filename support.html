Support

Help for the useful bits that have gone slightly sideways.

If Shelf-ish is misbehaving, we would like to hear about it. If you simply need a hand, that is welcome too.

Support email

Reach us at shelfishapp@gmail.com for help with bugs, unexpected behaviour, or questions about how Shelf-ish works.

Expected response time

We aim to reply within two business days. If something is affecting saved clips or sync, mention that in the subject line so it can be prioritised.

Best way to report a bug

Send a short description of what happened, what you expected instead, and the steps that led up to it. Screenshots are welcome. Computers can be strangely coy witnesses.

What to include in a support request

  • The device and platform you were using, such as macOS, iPhone, or Apple Vision Pro.
  • Your app version and operating system version.
  • A brief description of what you expected to happen.
  • What actually happened instead, including any error message.
  • Whether the issue happens every time or only occasionally.
  • A screenshot or screen recording if it helps explain the issue clearly.

How to report a bug

Send an email to shelfishapp@gmail.com with the subject line Bug report. If the problem involves a specific clip type, mention whether it was text, a link, code, audio, a screenshot, or something else.

If the app appears to be syncing incorrectly, include which devices were involved and whether iCloud sync was enabled.

Frequently asked questions

Clear answers to the questions people usually ask first.

What platforms does Shelf-ish support?

Shelf-ish is designed for macOS, iPhone, Apple Vision Pro, and supporting widgets.

Does Shelf-ish sync across devices?

Shelf-ish can use CloudKit when it is available, with local storage as a fallback when it is not. That means it still works on a single device even if sync is not active.

Does the app watch my clipboard all the time?

On supported platforms, live capture is optional. Users can pause capture, exclude certain apps, or use manual save actions instead.

How do expiring clips work?

Unpinned clips can expire automatically after a set time, which helps keep the shelf tidy. Important clips can be pinned or snoozed so they stick around longer.

Why is a preview or transcript missing?

Some features depend on network access, platform capabilities, or optional model downloads. If a preview does not load, ask the user to check connectivity and then try again.

What should I do if the app feels slow or stuck?

Restart the app, check your operating system version, and confirm whether the issue happens with one clip or every clip. If it persists, send the steps to reproduce it.
