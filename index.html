A few useful answers

Before you
make room.

Which connectors can I use now?

Safari, Chrome, Excel, Obsidian and VS Code context are out now for Mac. Chrome requires Shelf-ish 1.2 or later and the separate Chrome Web Store extension. Slack is coming soon. See the connector setup guides.

Does it collect everything I look at?

No. Context capture is tied to eligible copies from sources you enable, with the required permissions. Optional surrounding text is bounded. You can pause capture or disable a source.

Do I need Apple Intelligence?

No. Save, search, pin and paste without it. Optional language tools need a compatible Mac with Apple Intelligence enabled and its models ready.

What about the other devices?

The Mac app is available now. iPhone is coming soon. The Duo, Watch and Vision Pro artwork previews wider-platform work; it does not mean every version is available to download yet.

Is there a subscription?

No subscription. The Mac App Store listing has the current price, requirements and release details.
